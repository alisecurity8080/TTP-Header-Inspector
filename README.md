# 🌐 HTTP Header & API Security Inspector

A lightweight Python tool designed to send custom HTTP headers and inspect server response metadata during web security research and API testing.

## 🎯 Key Capabilities
- Custom `User-Agent` and `Accept` header injection.
- Detailed extraction and display of server security response headers (`Server`, `Set-Cookie`, CORS headers, etc.).
- Input error handling and clean response formatting.
